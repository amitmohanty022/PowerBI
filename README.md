# Power BI Dashboards & Power Query Practice

Power BI reports and Excel workbooks built while learning data modelling, Power Query transformations and advanced visuals.

## 🔗 How to view

`.pbix` files open in [Power BI Desktop](https://www.microsoft.com/power-platform/products/power-bi/desktop) (free, Windows). Download a file from the table below with the **Download raw file** button on GitHub, then open it. They are not published to the Power BI web service, so there is no public web link yet.
